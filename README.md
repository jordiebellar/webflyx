# WebFlyx

A small collection of plain-text and CSV data files describing a fictional movie catalog ("WebFlyx") — titles, a classics list, and per-movie quote files. This is a Boot.dev exercise repo used for practicing Git fundamentals (commits, branches, etc.), not an application — there's no code here, just structured content.

## Contents

- `titles.md` — a list of movie titles in the WebFlyx collection
- `classics.csv` — a comma-separated list of classic movies with director and release year
- `quotes/` — a directory of markdown files, one per movie, each containing a short list of memorable quotes (currently covers *Dune* and *Star Wars*)
- `contents.md` — a short index describing the files above

## Structure

```
.
├── contents.md
├── titles.md
├── classics.csv
└── quotes/
    ├── dune.md
    └── starwars.md
```

## Notes

- Movie quotes are excerpted for reference/study purposes only.
- This repo doubles as a Git practice ground — expect its history and branches to matter more than the file contents themselves.
